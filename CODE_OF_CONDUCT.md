# Code of conduct

VIGO is a welcoming project. Everyone taking part in issues, pull requests and discussions is expected to:

- be respectful and constructive, and assume good faith;
- accept criticism of ideas without taking it as criticism of people;
- avoid harassment, discrimination, personal attacks and publishing others' private information.

Maintainers may edit, hide or remove contributions that break these rules, and may block repeat offenders.

To report a problem, contact the maintainers through the vigo-project organization page on GitHub, or use a
private report as described in [SECURITY.md](SECURITY.md) when the matter is sensitive. Reports are handled
confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
